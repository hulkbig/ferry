# 发布检查

本文供维护者发布时使用。当前目录是源码候选，尚无正式公开发行版；本地测试、托管 CI、真实供应商验证和生产验收分别记录。

面向 Docker Hub 的安装、展示、文档与用户验收项目见[对外发布与展示清单](distribution/README.md)。

## 发布前确认

| 范围 | 需要保留的结果 |
| --- | --- |
| 版本身份 | 准确源提交、公开提交身份、版本号与构建元数据；不能用移动中的分支代替 |
| 产品检查 | 相关测试、完整构建、控制台、Skill及受影响并发检查 |
| 安全与依赖 | 当前源码的秘密／静态／漏洞检查，记录工具版本、规则范围与漏洞库日期 |
| 来源与许可 | 逐项确认引入材料的来源；LICENSE、NOTICE、LICENSES随实际分发物完整交付 |
| 分发产物 | 对准确二进制与镜像生成checksum、SBOM及可验证来源信息，并核对嵌入资源 |
| 用户路径 | 按公开文档完成干净安装、初始化、配置、请求、重启和备份恢复 |
| 支持入口 | 确认可用的仓库地址、私密安全报告方式及支持版本；更新SECURITY.md |
| 变更说明 | 写明新增行为、配置／数据兼容性、迁移步骤和已知限制 |

## 结果如何表述

- 命令失败、检查未执行、环境不满足分别注明，不能折算为通过。
- 旧构建的扫描结果只适用于旧产物；源码、依赖、嵌入内容或打包材料变化后重新判断检查范围。
- 离线fixture证明处理逻辑，不证明真实账号准入。记录实际测试的供应商、协议、模型和客户端范围。
- 通过另一个网关验证转发，不证明可以停用该上游。
- 声明文件与SBOM提供来源线索，不单独构成全部权利已确认的结论。

## 当前交付阶段

`hulkbig/ferry` 是计划使用的公开源码入口。当前为本地源码候选；仓库可见性、公共 CI 和发行结果须在实际交付时核验。构建与发布方式见[发布说明](release.md)。

公开仓库、正式版本号、发行校验材料和面向外部用户的私密安全报告入口仍需在正式发布前确认。本地验证成功不代表已经公开发行；安装示例中的版本地址在对应 Release 发布前不可用，项目不承诺响应时限。

## 生产迁移

替换现有实例前，单独验收实际配置、账号、客户端Key、历史数据、生产负载与回退方案。保留备份及恢复点，并确认上游调用不会因双实例后台任务重复执行。公开版本完成发布，不自动授权任何私有生产切换。
