# Ferry 1.0.0

Ferry 1.0.0 is the first stable release. It retains the 0.1.1 API and configuration format, including the Codex usage reset-clock correction and quota protection.

Ferry 1.0.0 是首个稳定版本，沿用 0.1.1 的 API 与配置格式，包含 Codex 用量刷新及额度保护修复。

## Changes / 变更

- The public repository is the common product baseline. Formal deployments can use the exact published image by digest, with no application rebuild.
- Deployment receivers can be bound to separate Compose projects and local ports so candidate checks cannot accidentally validate or stop the stable instance.
- Installation examples and support policy now target 1.0.0. Stable and candidate instances require separate data directories; traffic selection does not synchronize data.
- 公共源码作为通用产品基准；正式部署使用已校验的公开镜像，候选实例与正式实例隔离。

## Upgrade / 升级

No new database migration or client configuration change is introduced by this release. Keep the existing data volume, take the appropriate backup, and update the pinned image. Do not run two instances against the same SQLite directory or let them concurrently renew the same OAuth grant.

本次没有新增数据库迁移或客户端配置变更。升级时保留原数据卷并按现有策略备份；禁止两个实例共享 SQLite 目录或同时续期同一 OAuth 授权。1.0.0 延续 0.1.1 的功能与已知上游限制，不表示所有模型或账号均可调用。

```bash
curl -fsSLo compose.yaml https://github.com/hulkbig/ferry/releases/download/v1.0.0/compose.yaml
docker compose up -d
```

Linux AMD64 / ARM64: `bighulk/ferry:1.0.0`。管理控制台 / Console: **http://localhost:17910**。

Release assets include Compose, per-platform SBOMs, the image index and SHA256SUMS. Verify the desired platform digest before production use; `latest` is a convenience tag, not a production pin.
