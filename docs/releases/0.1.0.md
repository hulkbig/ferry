# Ferry 0.1.0

首个公开版本。为 AI 长任务提供稳定入口：限流等待、故障接力、并发排队，以及可由 Agent 使用的管理 API 和 Skill。

## 安装 / Install

```sh
curl -fsSLo compose.yaml https://github.com/hulkbig/ferry/releases/download/v0.1.0/compose.yaml
docker compose up -d
```

控制台 / Console: **http://localhost:17910**。创建管理员，添加自己的上游，再创建客户端 Key。

- Docker Hub: `bighulk/ferry:0.1.0`，Linux AMD64 / ARM64。
- [中文安装与恢复指南](https://github.com/hulkbig/ferry/blob/v0.1.0/docs/guide/docker.md) · [English installation and recovery](https://github.com/hulkbig/ferry/blob/v0.1.0/docs/guide/docker.en.md)
- 附件包含 Compose、各架构 SBOM、镜像 manifest 和 SHA256 校验文件。镜像版本元数据与 CI 检查绑定准确源码提交。

## 使用范围

支持 OpenAI Chat、Responses、Anthropic Messages 入口。协议转换、工具与推理能力取决于实际路由；原生协议优先，跨协议并非无损等价。

恢复受时间和次数预算约束，并响应客户端取消；已经提交可见输出的流不会拼接另一条上游流。并发控制不保证账号不会被封禁。

部分原生账号驱动仅完成离线测试，未逐一完成真实账号登录与推理验证，详见[渠道支持](https://github.com/hulkbig/ferry/blob/v0.1.0/docs/provider-channel-coverage.md)。不提供上游账号或额度。

## 账号导入与模型同步

在 Settings → Import & Migration 中预览并导入支持的 sub2api / CLIProxyAPI 账号与客户端 Key，导入对象保持禁用，需审核后启用。支持范围与凭证刷新边界见[导入指南](https://github.com/hulkbig/ferry/blob/v0.1.0/docs/guide/credential-import.md)。

自动创建逻辑模型的数量限制只适用于聚合渠道白名单；其他渠道补齐缺失的同名逻辑模型。详见[模型同步](https://github.com/hulkbig/ferry/blob/v0.1.0/docs/provider-model-sync.md)。Settings 后台刷新只在管理员登录后运行。

## 请求速度

请求列表每条记录和详情显示 `tokens/s`。按输出 tokens 与请求总耗时计算；进行中或数据不足时显示 `—`。

## 数据与升级

单实例 SQLite，数据保存在命名卷 `/data/state`。手动 `-backup-to` 和定时备份默认／固定只保存当前配置及恢复凭据，不保留历史请求、会话、旧配置版本和草稿。需要迁移完整历史时，手动备份显式添加 `-backup-history`。配置备份恢复后历史为空；升级前选择所需范围并校验、演练恢复。回退镜像不等于回退数据库。

这是首个公共版本，没有前一公共版本的升级结果。旧内部部署的 `/data` 布局需经备份恢复迁移；不要直接改变已有容器的数据路径。

Apache-2.0。镜像包含许可证与第三方声明。

## Codex 额度保护

默认任一订阅额度窗口使用达到 98% 时暂停连接，等待相应 reset。付费 Credits 默认关闭；开启后允许超过阈值并使用付费额度，AutoReset 重置卡独立管理。优先读取推理响应携带的额度信息，缺失或过期时查询 usage。并发请求与上游记账延迟仍可能产生超出阈值的使用。
