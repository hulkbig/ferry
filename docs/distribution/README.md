# 对外发布与展示

本目录保存 Ferry 的公开发行流程和介绍材料。具体版本是否可安装，以正式 Release、镜像标签和对应验收结果为准；文档或候选构建的存在不表示已经发行。

## 内容入口

| 材料 | 用途 |
| --- | --- |
| [公共发行流程](releasing.md) | 源码审核、CI、双架构镜像、时间窗口和发行验收 |
| [Docker Hub 介绍](dockerhub.md) | 镜像简介、安装、备份、升级和支持入口 |
| [介绍文案](announcement.md) | 产品用途、使用场景和配图说明 |
| [品牌与文案](../brand.md) | 产品名称、表达与视觉约定 |
| [资产来源](../asset-provenance.md) | 图形来源与第三方许可 |

## 核对公开入口

- GitHub README、Docker Hub 和版本说明应使用同一版本与安装路径。下载链接、图片和文档必须可公开访问。
- 用户应能从空环境完成安装、管理员初始化、首次请求、备份与恢复；真实上游验证只覆盖实际使用过的账号和路由。
- 镜像应覆盖声明的架构，附带 SBOM、许可证和校验文件。正式版本标签不覆盖，升级与数据迁移边界写入版本说明。
- Issues 和私密漏洞报告入口应经过验证。界面截图使用示例数据，日志、数据库、凭据和真实对话不作为公开展示材料。
- 中英文材料应保持功能范围、安装方式和限制一致。示意图不作为性能或真实账号验证的证据。

发行检查及实际发布步骤见[公共发行流程](releasing.md)。候选阶段保留准确的未发行提示，完成公共验收后再更新对应文案。
