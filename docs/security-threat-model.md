# 自托管安全边界与待验证风险

本文描述当前本地候选的信任边界，不是渗透测试报告或公开发布批准。
候选状态及未完成检查见 [发布准备状态](release-readiness.md)，安装、备份与恢复见
[运维说明](guide/operations.md)。本版本尚未完成全部安全和来源审核。

## 支持边界

原生示例配置将管理和推理端口绑定到 loopback；Compose 示例仅向宿主 loopback
发布端口，但容器内部监听所有接口。同网络的不可信容器仍可能访问服务。
首次启动应在受控本机立即初始化管理员，完成前不要开放网络访问。
产品初始化接口本身不提供独立的一次性安装证明，先到达接口的人可以创建管理员。
示例的本机绑定不能被理解为允许管理端直接暴露公网。

管理员、运行主机及其存储属于受信任边界。自定义 Provider 可以访问合法的内网服务，
因此不能将“管理员能设置任意 URL”视为安全的多租户能力。上游响应、模型内容、
导入文件、客户端请求和工具参数均按不可信数据处理。

## 数据与权限

- SQLite、WAL、备份及旧副本可能包含上游凭据、OAuth token 和可恢复的客户端 key。
  文件权限限制不等于静态加密；当前不能声称数据库或默认备份已加密。
- 客户端认证使用 key hash，但部分 key 同时保存可恢复值。管理员的高风险回显权限、
  运行主机及备份访问权限都必须按可以读取凭据的权限管理。
- Debug 请求/响应采集可能保存敏感正文。字段脱敏和截断不能保证识别正文中的全部秘密。
  开启前检查实际设置，限制采集时间和访问范围；删除当前记录不等于删除所有旧备份。
- 管理会话、CSRF 校验、Management Token 的高风险开关与撤销机制提供不同的权限边界。
  高风险 token 能执行敏感变更，不应分发给只需推理或只读诊断的客户端。
- 请求账本中的模型、渠道、时间、用量、错误和 trace 也可能揭示业务信息；导出前需要审阅。

## 风险与必要证据

| 范围 | 尚需处理或明确接受的风险 | 需要的验证 |
| --- | --- | --- |
| 初始化与登录 | 首次管理员抢注、登录耗尽、代理来源与公网暴露边界 | 未初始化隔离、并发初始化、认证失败限速、代理部署检查 |
| Provider 网络 | SSRF、云元数据访问、跨主机重定向、DNS rebinding；合法 LAN 不能一概禁止 | 对发现、探测和真实推理统一核对地址策略、IPv4/IPv6、重定向和凭据转发 |
| secret 与 key | 静态明文、管理员回显、历史副本及恢复后重新生效 | 权限、脱敏、轮换撤销、备份保护、恢复后身份及权限核对 |
| OAuth | callback/state 重放、错误账户、刷新失败、token 存储和供应商使用条件 | 各支持流程的账户绑定、过期、撤销、失败处理和日志检查 |
| Debug 与账本 | 正文或诊断泄漏、保留策略、删除与 WAL/备份残留 | 默认设置、访问控制、容量与截断、清理及恢复行为 |
| 资源与协议 | 大请求、慢客户端、长流、并发、工具参数及畸形上游响应耗尽资源 | 三协议契约、取消释放、队列限制、超时和部署规模容量测试 |
| 配置与迁移 | 旧备份或 revision 重新引入旧凭据、端点或较弱策略 | CAS、迁移、恢复前后安全配置对照、失败恢复及支持版本边界 |
| CI 与发布 | 被替换的工具或依赖、无来源证明的产物、公开工作流权限过大 | 固定工具与输入、秘密/漏洞/源代码检查、不可变产物和独立来源验证 |
| 公开材料 | 私人标识、运行信息、secret、未知来源代码或资产 | 源码与嵌入资产审核、声明清单、历史与分发产物检查 |

已有本地测试包含认证/CSRF、三协议、取消、并发槽位、分钟级模拟流、备份恢复和
核心模块 race 检查。这些证据不代表真实供应商、所有客户端、所有部署方式或对抗性
安全测试均已通过。发行检查需要绑定准确源版本和产物；本地旧报告不自动覆盖后续变更。发布所需结果见发布检查文档。
